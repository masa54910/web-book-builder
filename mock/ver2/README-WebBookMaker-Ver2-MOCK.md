# WebBookMaker Ver.2 完成モック

## 基準ファイル

- `WebBookMaker-Ver2-MOCK-SOURCE.html`

このHTMLを、WebBookMaker Ver.2のUI・画面構成・余白・配色・導線・ロゴの基準として使用してください。

## Copilotへの実装指示

- HTMLをそのまま本番コードへ貼り付けない
- Next.js / TypeScript / Tailwind または CSS Modules へコンポーネント分割する
- モックのセクション順、レイアウト、改行、余白、色、角丸、影、半透明表現を忠実に再現する
- 独自の再設計は禁止
- 既存の Reader / PublicBookPage / paginateText / slug / サンプル作品「星降る街の小さな記録」は流用する
- Draft保存、認証、公開導線など既存機能を壊さない
